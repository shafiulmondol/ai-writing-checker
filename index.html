Model / method
This version uses the DACTYL DeBERTa-v3-large detector, an ONNX conversion of the original model. The detector is designed with low-false-positive detection in mind. The browser loads the model from Hugging Face through Transformers.js and runs inference locally in the browser when WebGPU is available.
Important limitation
AI detection is probabilistic and cannot prove authorship. The displayed percentage is the model's AI-like probability estimate, not a literal percentage of words written by AI. Very short text is rejected because short samples are unreliable. This version is intended for English writing.
