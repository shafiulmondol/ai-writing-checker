Model / method

Uses onnx-community/tmr-ai-text-detector-ONNX through Hugging Face Transformers.js. The TMR classifier labels 0=human and 1=ai. Long documents are divided into overlapping windows because the underlying RoBERTa model has a finite input length; sentence scores are averaged from windows containing each sentence.

Important limitation

AI detection is probabilistic, not proof of authorship. The model is primarily trained for English and can behave differently on out-of-domain writing. Do not use this result alone for an academic misconduct decision.
